Installer SoukLink Order Desk

Le navigateur intégré à Codex ne peut pas installer une application. Ouvrez cette page dans Microsoft Edge ou Google Chrome sur votre ordinateur, puis suivez les étapes ci-dessous.

01

Microsoft Edge

Ouvrez le menu ⋯, puis choisissez Plus d’outils → Applications → Installer ce site en tant qu’application.

02

Google Chrome

Ouvrez le menu ⋮, puis choisissez Caster, enregistrer et partager → Installer la page en tant qu’application. Selon votre version, l’icône Installer peut aussi apparaître dans la barre d’adresse.

✓

Après installation, l’application s’ouvrira dans sa propre fenêtre. Vos commandes resteront enregistrées sur cet ordinateur.
